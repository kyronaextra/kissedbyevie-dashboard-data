# kissedbyevie dashboard data

Public, sanitized JSON feed for [kissedbyevieapp.grok.me](https://kissedbyevieapp.grok.me).

- Fetch URL (GitHub raw, CORS `*`): `https://raw.githubusercontent.com/kyronaextra/kissedbyevie-dashboard-data/main/dashboard.json`
- Netlify URL (CORS `*`): `https://kissedbyevie-dashboard.netlify.app/dashboard.json`

The file contains only first names, @usernames, categories, estimated amounts, last activity times, and short notes. It does not include phone numbers, payment handles, Telegram numeric IDs, or message bodies.

Refreshed about every 30 minutes.
